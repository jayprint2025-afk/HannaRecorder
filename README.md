# Hanna Recorder Android
App local para recolectar 40 muestras: 20 positivas y 20 near-negative.

## Compilar sin Android Studio
Sube todo este proyecto a un repositorio GitHub, abre **Actions > Build Hanna Recorder APK > Run workflow**.
Al terminar, descarga el artifact **HannaRecorder-APK**. Dentro estará `app-debug.apk`.

La app solicita micrófono, guía todas las frases, permite escuchar/repetir y al terminar crea un ZIP que puede compartirse por WhatsApp.
